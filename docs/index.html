LA MAISON

Un mécanicien de poche pour les projets Python cassés. Elle travaille dans Termux, sans internet, toujours sur une copie.

Installer Voir le code

Les trois règles de la maison

  • Elle ne touche jamais à l’original. Elle travaille sur une copie, et vérifie que la copie est identique avant de commencer.
  • Elle ne ment jamais. Si elle n’a pas pu réparer, elle le dit. Un programme qui tourne encore n’est pas « ça marche ».
  • Elle parle en français simple. Pas de gros mots compliqués, le rapport s’écrit pour être lu.

Comment l’utiliser

  1. Construis la maison, une seule fois.

    maison construire

  2. Mets ton projet cassé dans la pièce entree.

    cp mon_jeu.py ma-maison/entree/

  3. Fais la copie de sécurité et la copie de travail.

    maison copier

  4. Répare la copie de travail. Le rapport s’écrit tout seul.

    maison reparer

  5. Lance la copie pour voir. Elle te demande confirmation avant.

    maison tester

Lance toujours les commandes depuis le même dossier : c’est là que se trouve ma-maison. Le projet réparé reste dans ma-maison/travail/…/copie/, car la pièce sortie n’est pas encore construite.

Ce qu’elle répare

Seulement les cas dont elle est sûre. Après chaque correction, Python revérifie le fichier. Si ça n’améliore rien, elle annule. Voici un vrai rapport :

jeu.py, ligne 2

avant
print 'debut'
après
print('debut')

Il manquait les parenthèses de print (Python 3).

jeu.py, ligne 4

avant
if x == 1
après
if x == 1:

Il manquait les deux-points à la fin de la ligne.

jeu.py, ligne 5

avant
print('un'
après
print('un')

Une parenthèse n’était jamais fermée.

Tout le reste, elle n’y touche pas. Elle écrit dans le rapport où regarder. Pour un paquet manquant comme pygame, elle te donne la commande pip install à faire quand tu auras internet.

Ce que le test peut répondre

Ça marche
Le programme s’est lancé et terminé sans erreur. Ça ne prouve pas qu’il fait ce que tu veux.
Ça plante
Il s’est arrêté avec une erreur. Elle te l’explique en français, puis refait un diagnostic.
Il tourne encore
Un jeu ou un serveur qui ne s’arrête pas. Elle ne dit pas « ça marche », elle dit qu’elle ne sait pas.
Je ne sais pas
Elle ne sait pas quel fichier lancer. Tu le lui dis avec --fichier nom.py.

Installer

Version 0.1.0, en développement. Il faut internet une seule fois, pour l’installation.

pkg install python git
pip install git+https://github.com/daboujohan-hub/maison-DAJ.git
maison --version

Pas encore là

  • Python seulement. HTML, JavaScript et Bash viendront un par un.
  • La pièce sortie : pour l’instant, on récupère le projet réparé à la main.
  • Le ménage avant la réparation, et la recherche d’un paquet déjà présent dans le téléphone.
  • La publication avec pip install la-maison : elle viendra plus tard.
